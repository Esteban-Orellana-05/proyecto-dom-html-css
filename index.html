definicion.js

Definición del DOM

El objeto document es el objeto principal con el que trabajamos del lado del cliente. Es la puerta de entrada del navegador hacia la página: a través de él obtenemos propiedades y métodos que permiten leer y manipular todo lo que compone la ventana, tanto el contenido visible del cuerpo de la página como los datos de la cabecera.

En otras palabras, el DOM es la representación en forma de objetos de un documento HTML, y ese objeto document es el punto de partida para acceder a cualquier elemento de esa representación.

caracteristicas.js

Características principales

La utilidad del objeto document está en la enorme cantidad de referencias que ofrece hacia elementos de la página, tanto del cuerpo como de la cabecera. Algunas de sus propiedades más usadas son:

  • document.body — devuelve el elemento <body> del documento.
  • document.title — devuelve el título de la página.
  • document.images — un array donde cada índice es una imagen de la página.
  • document.bgcolor — obtiene o define el color de fondo (nombre en inglés o valor hexadecimal).

También ofrece métodos para actuar sobre el documento:

  • open() — abre el documento.
  • close() — cierra el documento.
  • write() / writeln() — escribe expresiones HTML directamente en la página.
arbol-dom.js

El árbol del DOM

El objeto document está formado por un conjunto de nodos, y para acceder a un elemento concreto hay que entender esa jerarquía. Los dos tipos principales de nodo son:

  • Element — los nodos definidos por etiquetas HTML, como body, div o h1.
  • Text — el texto contenido dentro de un nodo elemento, considerado como su nodo hijo.

Cuando se recorre el árbol se habla de padre al referirse a un nodo superior, e hijo al referirse a uno inferior; los nodos que comparten un mismo padre son hermanos entre sí. El DOM ofrece propiedades para moverse por esa estructura:

  • parentNode — nodo padre.
  • childNodes — array con los nodos hijos.
  • firstChild / lastChild — primer y último nodo hijo.
  • previousSibling / nextSibling — nodo hermano anterior y siguiente. 
<ul>
  <li id="miLI">Coffee</li>
  <li>Tea</li>
</ul>

var x = document.getElementById("miLI").parentNode.nodeName;
// x tendrá el valor "UL", el padre del nodo li
acceso-elementos.js

Acceso a los elementos HTML

Para llegar a un elemento concreto del árbol, el objeto document ofrece tres métodos principales:

  • getElementById() — accede a un elemento por su atributo id. Como no puede repetirse un mismo id en el HTML, es la forma más directa y frecuente de llegar a un nodo concreto.
  • getElementsByTagName() — devuelve, como un array, todos los elementos que coinciden con la etiqueta indicada, en el mismo orden en que aparecen en el código.
  • getElementsByName() — devuelve los elementos que tienen un atributo name específico, también en el orden del código.
cambio-elementos.js

Cambio de los elementos

Una vez localizado un nodo, el DOM permite modificarlo. Dos formas comunes de hacerlo son:

  • innerHTML — reemplaza el contenido HTML interno de un elemento.
  • setAttribute(atributo, valor) — cambia el valor de un atributo del elemento HTML.

objetivos.js

Objetivos y utilidad dentro del desarrollo web

El DOM existe para que un lenguaje como JavaScript pueda comunicarse con el HTML después de que la página ya fue cargada. Su objetivo principal es representar el documento como una estructura de objetos manipulable, de modo que se pueda leer, añadir, eliminar o modificar contenido y estilos sin necesidad de recargar la página.

Esto es lo que hace posible la interactividad en la web moderna: formularios que validan en tiempo real, menús que se despliegan, contenido que cambia según lo que hace el usuario. Entender el DOM es la base para trabajar con cualquier framework o librería de JavaScript, porque todos, en algún punto, terminan apoyándose en estas mismas propiedades y métodos.
